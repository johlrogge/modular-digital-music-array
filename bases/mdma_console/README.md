# mdma_console

Web management console for MDMA. Built with Axum and Askama, it provides a browser UI for browsing the library, controlling playback, managing Bandcamp downloads, and exporting audio.

## Build

```bash
cargo build --package mdma-console
```

## Run

```bash
cargo run --package mdma-console
```

The console is available at `http://mdma-909.local` on a provisioned Pi.
