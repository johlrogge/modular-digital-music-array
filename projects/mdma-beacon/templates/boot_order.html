Shows the live EEPROM. A change staged here appears only after the next reboot.
The update is staged on the SD card and only applies when the Pi boots from it. For a hung NVMe system:
  1. With the NVMe disconnected, boot the beacon from the SD card and choose this.
  2. Reboot with the NVMe still disconnected, so the update applies from the SD card.
  3. Confirm this page now shows the live BOOT_ORDER 0xf461.
  4. Power off completely (never hot-plug the NVMe), reconnect the NVMe, then power on.
Restores the normal order. Reboot once with the SD card inserted so the update applies, then remove the SD card.
